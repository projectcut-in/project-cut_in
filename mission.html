OUR MANIFESTO

なぜ私たちは、
「合作」にこだわるのか。

映像制作は孤独な作業になりがちです。1フレームの調整、1音の配置、1枚のイラストに何十時間も向き合いながら、たった一人で作品を完成させるクリエイターが多く存在します。

しかし、異なる作風や専門技術を持つクリエイター同士が「同じ1本のタイムライン」の上で出会い、互いのパートを繋ぎ合わせたとき、個人の想像をはるかに超える熱量と化学反応が生まれます。

「それぞれの個性をぶつけ合う。皆それぞれの考えがあっていい。クリエーター魂を燃やせる場所を。」
Project CUT-INは、その信念のもと、すべての参加者が主役として輝ける合作制作スタジオを目指しています。

THREE CORE VALUES

3つの制作指針

VALUE 01

CROSSOVER

個性の交差と尊重

手描きアニメーション、モーショングラフィックス、3DCG、音MAD・リミックス音源など、使用ソフトや表現手法の枠を設けません。After Effects、AviUtl、CLIP STUDIO PAINT、Blender、YMM4など、各自が最も得意とする環境で培った個性をそのまま作品に持ち寄ることができます。

VALUE 02

SEAMLESS CUT

繋ぎ（カットイン）の美学

「1秒で、視線を奪う。次のパートが待ちきれなくなるPVを。」—— Project CUT-INが最も重視するのは、パートとパートが切り替わる瞬間の演出です。前後のクリエイター同士が動きのベクトルや色調、カメラワークのバトンを緻密に受け渡すことで、オムニバスでありながら1本の映画のような没入感を生み出します。

VALUE 03

CREATIVE STUDIO

制作チームとしての誠実さ

合作の途中で頓挫する「エタり」を防ぎ、すべてのクリエイターが安心して制作に没頭できるよう、明確なスケジュール設計、技術レギュレーションの事前共有、適切なクレジット表記と楽曲・素材の権利配慮を徹底しています。
