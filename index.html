01 / MISSION & ABOUT

Respect all,
Match them.

Project CUT-INは、「それぞれの表現を尊重し、合わせることで最高のPVにする」ことをミッションに掲げるPV合作制作スタジオです。単なるパートの集合ではなく、1本の映像作品としての完成度と、クリエイター同士が刺激し合える誠実な制作環境を追求しています。

VALUE 01 /01

CROSSOVER

個性の交差

手描きイラスト、モーショングラフィックス、3DCG、リミックス音源。異なる専門領域を持つクリエイターが同じタイムライン上で交わり、一人では到達できない表現を生み出します。

VALUE 02 /02

SEAMLESS CUT

繋ぎの美学

「次のパートが、待ちきれなくなるPVを。」
パートが切り替わる1秒のカットイン演出と、前後のクリエイターによる緻密なバトンパスにこだわり、視聴者の視線を惹きつけ続けます。

VALUE 03 /03

CREATIVE STUDIO

制作チームとしての誠実さ

明確なスケジュール管理、レギュレーションの整備、コミュニケーション環境の整備。すべてのクリエーターが安心して最高のPVを制作できる環境づくりを目指しています。

04 / FOUNDER'S MESSAGE

COMMENT / 創立者の声

FOUNDER / REPRESENTATIVE
創立者 なーさい
Project CUT-IN 創立者・代表

「それぞれの個性をぶつけ合い、クリエーター魂を燃やせる場所を創りたい。」

私はもともとそのような文字PVだとか、モーショングラフィックスとか、作ることがそこまで好きではありませんでした。ですが、中1の頃にとあるPVなどを制作されているYouTubeクリエーターの方に出会いました。 そこで私はありきたりな表現ですが全身に電流が走ったかのようにビビビっと来てしまったんです。それに私は感化されて、文字PVだとかを作り始めたんですが、思うようにうまく行かず途中で断念して放棄しちゃいました。 ですが、中2の私は優秀でした。その途中のymmp.って言うんですけどね、プロジェクトファイルを見つけて、また1から編集し始めて、ちょっとYouTubeに投稿したんですよ。そしたら、想いのほか見てくれることが嬉しくて。
ですが、完成できたのはその頃の友のおかげでした。その友と協力して作り上げた、あの経験は今の私でもとても大切な経験となっています。皆さんにもそのような言葉にできないあの経験をこのプラットホームを通して経験してほしいです。
